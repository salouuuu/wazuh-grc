# Wazuh GRC — Security Operations & Governance Platform

## 📌 Overview

**Wazuh GRC** is a web-based security management platform that integrates **Wazuh** with a **Laravel-based GRC (Governance, Risk and Compliance)** application.

The project aims to bridge the gap between **Security Operations Center (SOC)** monitoring and **GRC processes** by transforming security alerts generated by Wazuh into structured security incidents that can be analyzed, assessed, and tracked from a centralized interface.

The platform allows security analysts to move from:

**Security Alert → Incident → Risk Assessment → Compliance Evaluation → Treatment & Follow-up**

## 🎯 Objectives

The main objectives of the project are:

* Integrate **Wazuh** security monitoring with a GRC platform.
* Centralize and manage security incidents.
* Automatically import relevant Wazuh alerts into the GRC application.
* Assess incident **probability, impact and risk level**.
* Associate incidents with compliance requirements.
* Track incident treatment and corrective actions.
* Provide security analysts with a unified SOC/GRC workflow.

---

## 🚀 Main Features

### 🔐 Wazuh Integration

The application communicates with the **Wazuh Indexer** to retrieve security alerts.

The integration:

* Retrieves recent Wazuh alerts.
* Filters alerts according to their severity.
* Imports relevant alerts into the Laravel application.
* Prevents duplicate incident imports.
* Stores the original Wazuh alert identifier.
* Converts security alerts into manageable GRC incidents.

---

### 🚨 Incident Management

Security incidents can be:

* Listed
* Viewed in detail
* Analyzed
* Assigned a severity
* Given a probability and impact
* Associated with a risk level
* Associated with compliance requirements
* Assigned a treatment/status
* Documented with comments and actions

---

### 📊 Risk Assessment

The application provides a risk assessment based on:

* **Severity**
* **Probability**
* **Impact**

The resulting risk level can be categorized as:

| Level    | Classification |
| -------- | -------------- |
| Low      | Faible         |
| Medium   | Moyen          |
| High     | Élevé          |
| Critical | Critique       |

The risk assessment helps analysts prioritize incidents according to their potential impact.

---

### 📋 Compliance Management

Incidents can be associated with compliance controls and evaluated according to their current status.

The application supports compliance follow-up through:

* Compliance controls
* Evaluation status
* Comments
* Evidence
* Corrective actions
* Treatment tracking

## 🔄 Alert-to-Incident Workflow

The main workflow is:

```text
1. Security event occurs
          ↓
2. Wazuh detects the event
          ↓
3. Wazuh generates an alert
          ↓
4. Alert is stored in Wazuh Indexer
          ↓
5. Laravel retrieves the alert
          ↓
6. Alert is converted into a GRC incident
          ↓
7. Risk is assessed
          ↓
8. Compliance is evaluated
          ↓
9. Treatment and corrective actions are tracked
```

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/salouuuu/wazuh-grc.git
cd wazuh-grc
```

### 2. Install PHP dependencies

```bash
composer install
```

### 3. Install frontend dependencies

```bash
npm install
```

### 4. Configure the environment

Copy the example environment file:

```bash
cp .env.example .env
```

Generate the Laravel application key:

```bash
php artisan key:generate
```

Then configure the required database and Wazuh Indexer variables in `.env`.

> **Important:** Never commit the `.env` file or real credentials to GitHub.

### 5. Configure the database

Create the application database and configure:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=grc
DB_USERNAME=
DB_PASSWORD=
```

### 6. Configure Wazuh

Configure the Wazuh Indexer connection:

```env
WAZUH_INDEXER_URL=https://<WAZUH_INDEXER_HOST>:9200
WAZUH_INDEXER_USERNAME=
WAZUH_INDEXER_PASSWORD=
```

Replace the placeholders with your own environment values.

### 7. Run migrations

```bash
php artisan migrate
```

### 8. Start the Laravel application

```bash
php artisan serve --host=0.0.0.0
```

The application will then be accessible from the configured host and port.

## 🔄 Importing Wazuh Alerts

The project includes an Artisan command for importing alerts from Wazuh:

```bash
php artisan wazuh:import
```

To limit the number of imported alerts:

```bash
php artisan wazuh:import --limit=10
```

The command retrieves relevant alerts from the Wazuh Indexer and creates corresponding incidents in the GRC application.

## 🔒 Security Considerations

This project handles security-related information. The following practices should be followed:

* Never commit `.env`.
* Never publish Wazuh credentials.
* Never publish database passwords.
* Never publish API tokens.
* Do not commit real security logs or sensitive Wazuh alerts.
* Use `.env.example` as a configuration template.
* Use appropriate access controls for the GRC application.
